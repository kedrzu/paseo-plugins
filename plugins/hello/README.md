# hello

Starter template, generated by `paseo plugin init`. Use it as a reference for the four-file
pattern; copy it when starting a new plugin.

What it wires up:

- `shared/greeting.ts` — a `defineRpc` contract with Zod input/output, validated on both sides
- `server/greeting.ts` — the handler, running in the plugin's Node subprocess on the daemon
- `client/greeting.tsx` — a React Native surface calling the RPC via `useRpc` + `useMutation`
- `index.server.ts` / `index.client.tsx` — the entries that register the handler and the surface

The surface shows up as a **Greeting** item in the app sidebar.

## Install

```bash
paseo plugin install /Users/kedrzu/Dev/paseo-plugins/plugins/hello
paseo plugin reload hello
```
